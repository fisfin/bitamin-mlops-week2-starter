## 이 문서 편집 방법

Ubuntu의 조별 폴더에서 `nano -I -l week2/README.md`로 엽니다.
방향키로 이동해 “작성”을 실제 값으로 바꿉니다. 복사한 URL은 Ctrl+Shift+V로 붙입니다.
Ctrl+O, Enter로 저장하고 Ctrl+X로 종료합니다. PDF 34~35쪽에 캡처·링크 복사 방법이 있습니다.
발표자료 30쪽대로 문서 branch에서 commit·push하고 PR·리뷰·merge합니다.
